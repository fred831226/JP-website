## 缺口

### GAP-1｜國外品牌是 V1 上線必要範圍，但 PRD 的發布門檻表述不夠明確

- **優先度：高**
- **來源要求：** 國外品牌必須與傑平品牌一同於第一版上線；國外品牌資料是阻塞上線的依賴。
- **目前承接：** PRD 提到自有與供應品牌，並在必要依賴中要求取得國外品牌規格、型錄、圖片及使用權。
- **缺口：** PRD 的 MVP 範圍沒有明確寫出「至少一組／全部已承諾的國外品牌內容必須隨 V1 上線」，依賴表也寫成「產品發布前」，可能被解讀為可先以傑平品牌上線，再補國外品牌。
- **建議歸位：** 在 V1 範圍或發布門檻中明示「國外品牌與傑平品牌同屬首發必要內容；若資料或權利未完成，V1 正式發布受阻」，並由 JP PUMP 確認首發品牌清單。

### GAP-2｜初始泵浦類型的權威映射規則未被保存

- **優先度：高**
- **來源要求：** 初始資料的泵浦類型以 Excel G 欄為準；原「用途」欄不可直接作為分類來源。
- **目前承接：** PRD 已定義泵浦類型為受控主分類，要求技術覆核、分類治理與 VBSG 跨類型處理。
- **缺口：** PRD 與 PRD addendum 都未保存「Excel G 欄是初始映射來源」以及「用途欄不得直接當分類」這兩條資料移轉規則。執行者可能用錯欄位建立分類或應用情境。
- **建議歸位：** 放入 PRD addendum 的產品資料整理／映射規則，並在初始資料驗證清單中列為可驗收條件；最終分類仍以 JP PUMP 技術覆核結果為準。

### GAP-3｜媒體盤點的可執行交接資訊被過度摘要

- **優先度：中**
- **來源現況：** `D:\JP handoff\media` 共 80 個檔案、約 653 MB，包含 JPG、CR2、PNG、AVIF；CR2 須轉檔，部分照片需裁切、去除干擾與統一品質，AI 圖須核對真實規格，外部品牌圖片須確認授權；目前 Logo 素材不足以確認為長期品牌母檔。
- **目前承接：** PRD 已涵蓋媒體權利、首頁影片／照片整理、效能、靜態封面、AI／外部素材的一般性風險，以及正式 Logo 的提供依賴。
- **缺口：** 實際檔案數量、容量、格式組成、媒體來源路徑、CR2 轉檔需求、現有照片品質問題及 Logo 母檔不足等交接事實未留在 PRD addendum。下游架構、設計與內容整理無法僅靠現有文件估算媒體處理工作。
- **建議歸位：** 將完整媒體盤點保留在 PRD addendum 或獨立媒體準備清單；主 PRD 維持目前能力與品質要求即可。

### GAP-4｜質化視覺方向與具體微互動意圖遺失

- **優先度：中**
- **來源要求：** 整體視覺應「完整、專業、現代而不花俏」；互動採克制的按鈕回饋、捲動動畫與產品圖片縮放。
- **目前承接：** PRD 已規範 Hero 循環影片、靜態降級、效能、手機與減少動態效果，NFR-4 也提到微互動不得妨礙閱讀。
- **缺口：** 「專業、現代、不花俏」的品牌感受與「克制」原則沒有被保存；按鈕回饋、捲動動畫、產品圖片縮放的預期也未在 PRD addendum 成為後續 UX 探索輸入。功能性條文雖完整，仍可能導向風格過度炫技或過度保守。
- **建議歸位：** 放入 PRD addendum 的 UX／視覺設計方向，作為 `bmad-ux` 的輸入；保留為方向而非硬性指定每頁動畫。

### GAP-5｜產品資料分布與極端系列規模未保留給 UX／架構

- **優先度：中**
- **來源現況：** 603 筆型號集中於 10 個系列，其中 `SB/SBI/SBN` 有 491 筆、`VBSG` 有 44 筆且跨多種泵浦類型；其餘系列規模差異大。
- **目前承接：** PRD 保存了總數、系列數、VBSG 例外、系列內型號規格表、手機不得遺失資料及分批整理需求。
- **缺口：** 各系列分布，尤其單一系列可能有 491 筆規格列的事實未保存。這會直接影響系列頁規格表的搜尋、分組、載入與手機閱讀設計，也影響效能測試資料集。
- **建議歸位：** 將型號分布表保留於 PRD addendum，並要求 UX／架構以最大系列資料量驗證系列頁，不必把分布明細塞入主 PRD。

## 已完整或合理承接的內容

### 資料與分類

- 系列為唯一介紹頁、型號為頁內規格列，已由 FR-10～FR-13 清楚承接。
- 一個系列可對應多個泵浦類型，VBSG 不複製系列頁，已被 A9、A13 與 FR-13 承接。
- 品牌、泵浦類型及應用情境可多路徑探索；同維度 OR、跨維度 AND 與任意篩選不索引均已有明確規則。
- 「產業／建案場景」是否成為第四維度，已由使用者確認為 V1 不採用（A8），屬已解決決策而非遺漏。
- Excel 的缺漏、版本重疊與 OCR 風險已被 FR-24、FR-25、NFR-11 及風險表承接。

### 媒體與案例

- 民生社區中心、高樓豪宅、亞運選手村、捷運站四類案例已由 FR-4、FR-20、上線依賴與風險表承接。
- 案名、年份、工作範圍、成果、照片、個資／安全資訊與第三方權利須於發布前核對，已被功能驗收、依賴及風險一致承接。
- 首頁影片須提供靜態替代、手機／節省數據／減少動態時降級，以及媒體不得破壞 Core Web Vitals，已由 FR-2、NFR-1、NFR-4 承接。

### 公司信任內容

- 法定名稱傑平有限公司、1998 年創立、估價／選型／供應／安裝／維修／顧問服務鏈與證據要求，已被 FR-3、產品目標、旅程與依賴承接。
- 自有品牌與供應品牌、服務能力與建案證據共同建立信任的意圖已保留。

### 語言、SEO 與技術限制

- V1 僅繁中、英文延後但資料模型與網址須可擴充，已由產品目標、FR-26、NFR-12、A18 及範圍外項目承接。
- V1 對僅使用英文的海外對象只能提供有限驗證，已由 A2、UJ-2 與風險表誠實揭露。
- 正式品牌、類型、應用情境與系列頁可索引；任意篩選組合不可形成 SEO 頁，已由 FR-27～FR-31 承接。
- 第一版不做複雜工程選型，已列為明確非目標。

### 後台策略的明確覆寫

- 原始 brief 要求單一管理者維護全部內容；後續使用者因產品更新頻率低、Excel 尚不完整且有指定維護者，明確改採混合模式。
- PRD 與 PRD addendum 已忠實記錄這項新決策：客戶只管理消息、案例及其圖片，產品資料由指定維護者透過受控、可版本化、可回復、可交接的流程維護。
- 後端與 CMS 刻意延後，Next.js 僅作為已確認的前端基礎；現有文件未錯誤承諾 Sanity、Payload、Decap 或自製後台。
