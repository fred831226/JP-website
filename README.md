# JP PUMP Website

Traditional Chinese industrial B2B public site for JP PUMP.

- **Application root:** repository root (Vercel Root Directory = `.`)
- **Project docs:** [`docs/`](./docs/README.md)
- **Authoritative planning:** `_bmad-output/planning-artifacts/`
- **Agent rules:** [`AGENTS.md`](./AGENTS.md)

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` (redirects to `/zh-tw`).

## Verify

```bash
npm run validate
npm run lint
npm run build
npm test
```
